# Fomo Verified Scanner

Research feed for Solana tokens traded through Fomo. No trading and no wallet connection.

The Helius key is not in this repository. On Vercel, add these environment variables, then deploy:

- `HELIUS_API_KEY` — your Helius key
- `CRON_SECRET` — a long random password you invent

Use the vercel.app link. The grok.me copy does not receive these variables.
